# Unified PDF Toolkit v0.6.0-beta.5

> **Installer lifecycle risk accepted for this controlled beta.** The
> checkpointed Windows installer lifecycle matrix was not executed because no
> checkpoint-capable disposable Windows VM was available. The maintainer
> explicitly waived this gate for `v0.6.0-beta.5` only. This is not a `PASS`,
> does not establish production readiness, and does not waive the standard gate
> for future releases. This release must remain marked as a prerelease.

The following runbook scenarios remain unverified because the checkpointed VM
matrix was not executed:

- Fresh installer lifecycle.
- Post-reboot launch and shutdown.
- Portable ZIP lifecycle acceptance. The runbook's clean-VM Scenario B was not
  executed; the packaged/PyInstaller application has separate startup/shutdown
  evidence described below.
- In-place upgrade from beta.4 to beta.5.
- Settings retention through uninstall.
- Managed OCR data retention through uninstall.
- Reinstall with retained user state.
- Upgrade behavior while the application is active.
- Checkpoint rollback and recovery to the beta.4 baseline.

The waiver lowers, but does not eliminate, installer risk.

### Historical packaged-app shutdown observation

A controlled local A/B investigation recorded packaged-app shutdown timeouts in
5/5 baseline runs and 5/5 candidate runs. Affected processes remained alive
beyond the normal 5-second close bound; diagnostic runs remained alive to about
15 seconds. Later normal-user desktop validation passed 20/20 without
reproducing the timeout, and the exact-head GitHub PyInstaller packaged smoke
passed. Classification: `HISTORICAL_NONDETERMINISTIC_FAILURE`.

Monitor this as a residual reliability observation during controlled beta use.
These results do not establish a root-cause fix or permanent elimination, and
they do not constitute installer shutdown lifecycle acceptance.

This controlled beta candidate improves the normal PDF workflows and desktop
interface. Tesseract remains the default OCR provider. The optional managed
Unlimited-OCR runtime remains local-only, consent-gated, and excluded from the
default application, portable ZIP, and installer.

## Highlights

### Clearer desktop workspace

- Groups tools into Organize, Convert & Extract, and Workspace sections.
- Shows a consistent workflow category, title, description, status, and primary
  action for every tool.
- Uses shared color, typography, field, button, progress, list, and table styles.
- Adds vertically scrollable tool content for smaller displays.
- Switches merge, split, PDF-to-Word, Page Manager, and Batch Queue between a
  two-pane layout and compact controls/preview tabs at the responsive boundary.

### Short, cancellable motion

- Adds application and dialog entry/exit transitions, animated tool switching,
  an active-navigation indicator, empty-list transitions, and output-ready
  feedback.
- Cancels superseded transitions during rapid navigation.
- Honors the Windows client-animation preference and supports the process-local
  `PDF_TOOLKIT_REDUCE_MOTION=1` override.
- Cancels pending Tk callbacks during shutdown so cached tool views do not leave
  stale queue callbacks after the window closes.

### Measured core workflow improvements

- Reads eligible PDF image pixels directly instead of encoding and decoding an
  intermediate PNG during compression analysis.
- Uses a conservative preview estimate to skip clearly unprofitable full-image
  JPEG work while preserving the existing exact comparison for borderline
  cases.
- Passes native PyMuPDF PNG bytes into PDF-to-Word Page Images output and opens
  a source PDF once for validation, page-range parsing, and text sampling.
- Keeps page order, page selection, OCR routing, image pixels, public CLI/GUI
  entry points, and output conflict behavior unchanged.

The maintained
[core workflow benchmark](../performance/core_workflow_benchmark.md) records
the fixture design, raw samples, profile evidence, regression checks, and scope
limits.

## Safety and compatibility boundaries

- The default application does not include PyTorch, Transformers, CUDA runtime
  packages, model weights, or a Hugging Face cache.
- The managed OCR flow does not update NVIDIA Driver software, replace system
  CUDA, edit `PATH`, change global Python, or upload documents.
- Existing beta tags and assets are immutable. Do not replace beta.4 assets with
  a locally rebuilt artifact that contains post-beta.4 commits.
- A successful source build, installer compile, or packaged-app smoke does not
  prove installer lifecycle behavior.

## Known limitations

- Installer lifecycle acceptance remains `DEFERRED` because no disposable
  Windows VM was available during candidate preparation.
- The desktop GUI has scripted Windows evidence at 780x880 plus programmatic
  wide/compact reflow checks; cross-platform visual appearance and every DPI,
  high-contrast, keyboard, drag-and-drop, and failure-dialog combination are
  not fully automated.
- OCR quality and Unlimited-OCR hardware support remain device- and
  revision-specific. This beta does not broaden those support claims.
- Performance measurements use synthetic fixtures on one Windows host and do
  not predict every document, storage device, or antivirus environment.
